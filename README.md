# LegalEase

LegalEase is a Generative AI-powered legal document generation platform designed to simplify the creation of structured and customizable legal documents.

The application uses Streamlit for the frontend, FastAPI for the backend, and Google Gemini for AI-assisted document generation.

---

## Project Architecture

```text
User
  ↓
Streamlit Frontend
  ↓
FastAPI Backend
  ↓
Gemini AI
  ↓
Generated Legal Document
  ↓
Editable Preview
  ↓
Document Formatter
  ↓
TXT / DOCX / PDF
